# 🤖 Desafio de Automação: Gestão de Peças

Este projeto simula um sistema de linha de produção para gestão e controle de qualidade de peças industriais, conforme o desafio proposto.

## Funcionalidades

* Cadastro de novas peças (Peso, Cor, Comprimento).
* Avaliação automática de qualidade (Aprovada/Reprovada).
* Gerenciamento de caixas (10 peças por caixa).
* Listagem e remoção de peças reprovadas.
* Geração de relatório final consolidado.

## Como Executar

1.  Certifique-se de ter o Python 3.10+ instalado.
2.  Execute o programa principal:

```bash
python main.py
